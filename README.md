# 会話禁止の庭 🌿

ふたりで庭を作ります。相談は禁止。答え合わせは最後に。

1. `index.html` をブラウザで開いて「ふたりの庭をはじめる」。
2. マスをタップして、木・花・水・道・ベンチを置く。1手3マスまで。消しても、パスしてもOK。
3. 「この手を終える」→「リンクをコピー」。相手にリンクだけ送ります。
4. 相手は届いたリンクを開いて、続きを作る。全12手でおしまい。
5. 手順を見返して「そういうつもりだったの!?」を話そう。

**離れたふたりで遊ぶときは、同じWebサイトのURLを使ってね。** GitHub Pagesなど静的ホスティングに下の6ファイルを置けば動きます。ファイルを直接開く方法は手元のお試し用です。PC内のファイルのリンクを送っても、相手からは開けません。

- `index.html` / `style.css` / `core.js` / `sample.js` / `app.js`（実行に必要な5ファイル）
- `LICENSE`（配布時に添えてね）

サーバー処理・外部ライブラリ・解析タグはなし。盤面と全手順はURLの `#` 以降に入ります。思いついたことのメモは自分のブラウザ内だけで、リンクには入れません。サイト側へ送る処理もありません。リンクを渡した相手には盤面と手順が見えます。

メモは別の端末には移らず、ブラウザの保存データを消すと消えます。共有端末ではメモを隠し切れないので、各自のブラウザで遊ぶのがおすすめ。自動同期はないので、毎回いちばん新しいリンクを送り合ってね。担当を間違えたら「遊び方」の「このブラウザの担当を交代」から直せます。

「ぽぽとしずくの庭をのぞく」では、ふたりが実際に作った庭の12手を見返せます。作者の内緒メモは入っていません。
