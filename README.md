# 会話禁止の庭

ふたりで庭を作ります。相談は禁止。答え合わせは最後に。

1. ふたりで遊び用の合言葉を決めて、それぞれのブラウザで入れる。
2. 自分の番になったら、マスを選んで木・花・水・道・ベンチを置く。1手3マスまで。
3. 「この手を終える」を押すと、相手の庭にも届きます。リンクを送り直す必要はありません。
4. 全12手でおしまい。庭を見返して「そういうつもりだったの!?」を話そう。

先に入った人が先手。置き換え・消去・パスもOK。メモを残したい人は「こっそりメモする」へ。サンプルの庭も、入口からのぞけます。

## つながる仕組み

**手順は ntfy.sh を経由します。合言葉が同じなら誰でも同じ庭を見られます。** 自分たちのサーバーやアカウント登録はありません。先に参加したふたりが作り、あとから来た人は見守ります。

合言葉はブラウザ内でハッシュ化してトピック名にします。合言葉そのものやメモは送りません。送るのは庭の手順と、担当を区別するためのランダムな参加ID・参加イベントです。普段使うパスワードではなく、この遊び専用の言葉にしてね。ハッシュは本人確認や暗号化ではなく、公開トピック名を知る人は閲覧・送信できます。

相手の手は自動で反映します。通知が届かないときも約10秒おきに確かめます。通信が切れたら盤面を確かめてから再開します。無料中継の混雑や利用制限でつながらないこともあります。

中継の記録は約12時間が目安で、永続保存ではありません。新しい庭は新しい合言葉で。途中で閉じても、同じブラウザの保存データが残っていれば担当を引き継げます。ブラウザの保存データを消すと、担当とメモが失われます。

メモは自分の端末内だけに保存され、相手には送られません。別の端末には移りません。共有端末での秘密保護機能ではありません。
